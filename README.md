# PyNetworkKit

Python-first networking primitives, composable transport contracts and reproducible learning labs.

> **Status:** pre-alpha / M0 bootstrap in progress. The repository name is `pynetworkit`; the intended Python distribution and import name is `pynetworkkit` (spelling to review before publishing).

## Roadmap

- **M0 (`0.1.0a1`)**: package bootstrap, pure domain kernel, async capability contracts, in-memory stream and automated validation.
- **M1 (`0.1.0a2`)**: localhost TCP/UDP socket adapters.
- **M2-M8**: asynchronous transport, protocol utilities, TLS policies, diagnostics, simulation and stable `1.0.0` API.

The implementation follows the *Software Design & Learning* convention: explain networking concepts, preserve architectural boundaries, demonstrate with tests and record relevant trade-offs as ADRs.

## Repository setup

Development environment and package metadata are being added through the M0 bootstrap pull request. There is no published release yet.
